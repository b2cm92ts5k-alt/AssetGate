# Asset Gate

[English](README.md)

**ตรวจโมเดล 3 มิติสำหรับเกม ทั้งใน Blender และใน Unity แล้วแก้ข้อที่ผิดก่อนเอาไปใช้ในเกมหรือขายบน Unity Asset Store**

ทำมาสำหรับคนที่ปั้นโมเดลเองหรือสร้างด้วย AI (Meshy, Tripo ฯลฯ) และอยากได้การตรวจที่ทำซ้ำได้ทุกชิ้น แทนการติ๊กเช็คลิสต์เอง

| ด่าน | ตรวจที่ | ตรวจอะไร |
|---|---|---|
| 1 | Blender add-on | เมชเสีย, หน้าตัดทะลุกัน, ทิศหน้า, ค่าตำแหน่ง/หมุน/สเกล, แบ่งสามเหลี่ยม, จุดหมุน, ชื่อ, แมทีเรียล, UV, ความละเอียดเท็กซ์เจอร์, ขนาดเท็กซ์เจอร์, แสงเงาที่ติดมาในเท็กซ์เจอร์, ค่าไฟล์ FBX, จำนวนโพลีกอน |
| 2 | Unity tool | ค่าการนำเข้า, แมทีเรียลแยกไฟล์, shader URP/Lit และช่องเท็กซ์เจอร์, ความมันเงา, ชนิดพื้นผิว, prefab, กล่องชน, LOD, ระบบสี, ฉากทดสอบมาตรฐาน + ภาพหน้าจอ, Console |
| 3 | Unity tool + หน้าเว็บ | โฟลเดอร์ของแพ็ก, ความยาวชื่อไฟล์, ฉากตัวอย่าง, README, Third-Party Notices, ไฟล์ที่ไม่ได้ใช้, ภาพหน้าขาย, ร่างข้อความหน้าขาย (เฉพาะโหมดทำขาย) |

**สองโหมด:** **ใช้ในเกม** สำหรับโมเดลในเกมของตัวเอง (ด่าน 1 + 2) · **ทำขาย** สำหรับแพ็กที่ขายบน Unity Asset Store (ด่าน 1 + 2 + 3)

## ความสามารถ

- กด **ตรวจ** ปุ่มเดียวในแต่ละโปรแกรม ผลบอกว่าข้อไหนไม่ผ่านและแก้ยังไง
- **ปุ่มแก้อัตโนมัติ** สำหรับข้อที่ไม่ผ่านส่วนใหญ่ — บอกก่อนว่าจะเปลี่ยนอะไร, Blender กด Ctrl+Z ย้อนได้, ไม่เขียนทับเท็กซ์เจอร์ต้นฉบับ
- **ปุ่มยืนยัน** สำหรับคำแนะนำที่ขึ้นกับงานของคุณ (เช่น ชิ้นส่วนที่ตั้งใจให้ซ้อนกัน หรือจุดหมุนที่บานพับ) — ไม่ใช่ทุกข้อเป็นกฎตายตัว
- **ส่งเข้า Unity** จาก Blender: ส่ง FBX และเท็กซ์เจอร์ PNG เข้าโปรเจกต์ Unity (สร้างโฟลเดอร์ให้เอง) และแปลง metallic-roughness ให้ใช้กับ URP ได้
- **ตั้งค่าอัตโนมัติ** ใน Unity: ค่าการนำเข้า, แมทีเรียล URP พร้อมใส่เท็กซ์เจอร์ถูกช่อง, prefab และกล่องชน ในคลิกเดียว
- คำแนะนำจำนวนโพลีกอนตามประเภทโมเดลและแพลตฟอร์ม
- ภาษาอังกฤษและภาษาไทย
- ไม่ส่งข้อมูลออกอินเทอร์เน็ต — ทุกส่วนคุยกันผ่านไฟล์ JSON ในโฟลเดอร์ข้อมูลในเครื่อง

## สิ่งที่ต้องมี

- Blender **4.2 ขึ้นไป** (ทดสอบแล้วกับ 4.5 และ 5.2)
- Unity **6 (6000.0) ขึ้นไป** ที่ใช้ **URP** (ทดสอบแล้วกับ 6000.3 และ 6000.5)
- Chrome หรือ Edge สำหรับหน้าเว็บ (เฉพาะโหมดทำขาย)

## ติดตั้ง

**Blender** — ดาวน์โหลด `asset_gate-1.0.0.zip` จาก Releases → Edit > Preferences > Get Extensions → เมนูลูกศร → **Install from Disk…** → ใน 3D Viewport กด N → แท็บ **Asset Gate**

**Unity** — Window > Package Manager → **+** → **Install package from git URL…**

```
https://github.com/b2cm92ts5k-alt/AssetGate.git?path=/unity/com.etlolz.assetgate
```

แล้วเปิด **Tools > Asset Gate > Open Window**

**หน้าเว็บ** (โหมดทำขาย) — เปิด `web/index.html` ด้วย Chrome หรือ Edge

## เริ่มใช้งานเร็ว

1. Blender: เลือก **โปรเจกต์ Unity** ในแผงครั้งเดียว
2. ใส่ชื่อ **โฟลเดอร์** และ **โมเดล** → **ตรวจ** → แก้ข้อที่ไม่ผ่าน ยืนยันข้อที่ดูแล้ว
3. **ส่งเข้า Unity** (ครั้งแรกช่อง FBX เว้นว่างได้)
4. Unity: เลือกไฟล์ FBX ใน `Assets/<โฟลเดอร์>/Meshes` → **ตั้งค่าอัตโนมัติ** → **ตรวจ**
5. โหมดทำขาย: **ตรวจทั้งแพ็ก** แล้วเปิดหน้าเว็บ เลือก `<โปรเจกต์ Unity>/AssetGate`

คู่มือฉบับเต็ม รวมทุกข้อตรวจและวิธีแก้: **[docs/MANUAL.th.md](docs/MANUAL.th.md)**

## โครงสร้าง repo

| โฟลเดอร์ | คืออะไร |
|---|---|
| `blender_addon/asset_gate/` | Blender extension (ด่าน 1, ส่งเข้า Unity) |
| `unity/com.etlolz.assetgate/` | Unity Editor package (ด่าน 2–3) |
| `web/index.html` | หน้าด่าน 3 — ไฟล์เดียว ไม่ต้อง build |
| `config/default.config.json` | เกณฑ์เริ่มต้น (คัดลอกไปโฟลเดอร์ข้อมูลตอนใช้ครั้งแรก) |
| `schema/` | JSON Schema ของผลตรวจ การยืนยัน state และ config |
| `tests/` | เทสต์ Blender, Unity batch และหน้าเว็บ |
| `tools/` | สคริปต์ build และตรวจ schema |
| `docs/` | คู่มือ |
